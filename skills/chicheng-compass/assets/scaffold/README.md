# ChiChengDocs

这是本项目的补充资料区，供人和 AI 查找项目背景、个人工作约束及需求资料。与仓库原有文档共存，原仓库规则继续生效。

## 从哪里开始

1. 阅读 [个人约束](constraints.md)，了解本资料区使用者的补充要求。
2. 按任务访问 [项目知识入口](knowledge/README.md) 或 [需求资料入口](requirements/README.md)。
3. 更详细的实现事实回到源码和相关工具核验。

当前内容是初始化骨架，不代表已经完成项目梳理。可以逐步补充真实知识，并把阅读入口加到这里；无需为了目录完整而创建空文档。

## 维护

资料区默认仅留在本地。显式使用 Compass 时先检查并设置 Git 的本地排除，不修改共享 `.gitignore`；已跟踪文件不受忽略规则保护。此设置不随提交传播，重新克隆后需要重新准备。

显式使用 Compass 的 `read` 阅读引导，`sync` 根据给定材料提出维护建议。知识更新先展示具体内容，经使用者同意后执行。需要拆分或增加索引时，按实际阅读需要组织，不要求固定模板。

如已产生维护提案，运行记录位于 `.compass/records/`；该目录按需创建，记录不属于正式项目知识。
