# 项目知识入口

项目知识尚未建立。本文只提供组织建议，不是本项目的架构或业务事实。

已预留 [项目专属信息](project-specific/README.md)，供后续补充自写脚本的用途与使用入口、项目专属约束等。开始任务时按需要检查其中适用的项目约束。初始化仅创建说明入口，不扫描、收集或填充这些内容。

可以先用一份项目概述说明项目目标、主要业务对象和模块关系；需要时再拆成模块文档、术语表、重要决策和重大变更，并在本入口保留简短导航。

每份知识尽量回答“负责什么、为何重要、与谁有关、到哪里继续查”。代码无法证明的决策原因，引用讨论或原有文档；尚未实施的设计明确标为计划。

按真实资料逐步补充后，把相关链接放在此处。格式与章节自由调整，无需逐文件总结源码。可自行维护内容，也可明确要求 Compass 在 `init` 中参考推荐流程开展首次知识建设；普通初始化不会自动开始扫描。已有知识之后可使用 `sync` 检查更新。
