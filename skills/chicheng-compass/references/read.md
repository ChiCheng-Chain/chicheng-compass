# 阅读引导

完成标准：先完成公共的本地忽略准备，再清楚说明本次目标、实际读到的约束和相关知识，以及缺失或冲突的背景；阅读阶段项目内容保持不变。

1. 阅读资料入口，再读其指向的个人约束；沿知识导航核对适用的项目专属约束。缺少 Compass 入口时，可以使用用户指定的文档；没有可用入口就说明并等待用户选择，不自行初始化。
2. 从用户任务提取涉及的业务概念或模块，循导航读取相关知识。单文档只需查相关部分；分层目录沿当前任务所在分支展开，不遍历其他主题和全部历史记录。
   核对入口及相关主题的基线分支、提交、更新时间与覆盖范围；与当前目标版本不一致或未记录时说明适用性风险，按需核验相关代码，不修改知识基线。
3. 需要更细的实现事实时，按任务定位代码。CodeGraph、Agent 搜索或其他工具均可；已有知识没有记录的原因和业务规则要明确标为未知。
4. 简短输出：当前项目与资料入口、相关约束、已读资料及任务阅读路径、仍需确认的事项。保留与原始材料的链接，便于继续开发。

这里没有固定知识 schema，也不要求每次读完概述、全部模块和术语表。若知识已经过期，可以指出问题，用户选择 `sync` 后再提出维护建议；`read` 自身不写提案或修改文档。

只有通用初始化说明时，明确“项目知识尚未建立”，不将骨架说明当成项目事实，也不启动全仓库首次建设。
